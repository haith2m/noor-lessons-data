# بيانات الدروس العلمية لتطبيق نور

هذا الريبو مصدر بيانات قسم **الدروس العلمية** في تطبيق نور. يحتوي على فهرس لدروس المسجد الحرام والمسجد النبوي المنشورة على يوتيوب، مصنّف حسب العلم ومربوط بأسماء المشايخ ومرتّب.

## المحتوى

- **قناتين:** [دروس المسجد الحرام](https://www.youtube.com/@twjehdm) و[دروس المسجد النبوي](https://www.youtube.com/@wmngovksa)
- **698 سلسلة** فيها **19,447 درس** لـ **118 شيخ**
- **11 تصنيف:** العقيدة، الفقه، أصول الفقه، الحديث، التفسير، السيرة، اللغة العربية، الآداب والرقائق، الخطب، التلاوات، محاضرات عامة
- **اللغة:** عربي، وفيه دروس إنجليزية عليها `lang: "en"`

## الملفات

```
data/index.json          القنوات والتصنيفات والمشايخ وكل السلاسل (بدون الدروس)
data/series/<id>.json    سلسلة وحدة مع دروسها
```

## ملاحظة

المقاطع ملك أصحاب القنوات. الريبو يحتوي على فهرس فقط بدون أي صوت أو فيديو، والتشغيل يكون عن طريق مشغّل يوتيوب الرسمي (embed). البيانات تتحدث تقريبا كل شهر.
